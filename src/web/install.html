Voice Button как приложение

Один раз установите сертификат на телефон — и страница перестанет ругаться, а браузер позволит поставить её как приложение с иконкой.

Скачать сертификат

Этот браузер не начинает загрузку сертификата: он блокирует такие файлы. Откройте эту страницу в Chrome — там файл скачивается сразу.

Android

  1. Скачайте сертификат по кнопке выше — файл окажется в «Загрузках».
  2. Настройки → Безопасность → Шифрование и учётные данные → Установить сертификат → Сертификат CA (на Android 12+: Настройки → Безопасность → Другие настройки безопасности → Установка сертификата → Сертификат CA).
  3. Выберите скачанный voice-button-ca.crt и подтвердите. Система попросит разблокировку экрана.
  4. Вернитесь на эту страницу — предупреждение о сертификате больше не появится. В меню Chrome появится «Установить приложение».

iPhone

  1. Нажмите «Скачать сертификат» и разрешите установку профиля.
  2. Настройки → Профиль загружен → Установить → введите код.
  3. Настройки → Основные → Об этом устройстве → Доверие сертификатам → включите полное доверие для «Voice Button».
  4. Откройте страницу в Safari → «Поделиться» → «На экран «Домой»».

Если браузер не начинает скачивание: на предупреждении о сертификате нажмите «Дополнительно» → «Перейти на сайт», вернитесь на эту страницу и нажмите кнопку ещё раз. Brave такие загрузки блокирует совсем — откройте страницу в Chrome.

Сертификат выпущен этим компьютером и подписывает только адресный сертификат сайта. Храните его ключ при себе: кто получит ключ, сможет подписывать сертификаты, которым телефон будет верить.

Voice Button as an app

Install the certificate on the phone once — the warning stops and the browser lets the page install as an app with its own icon.

Download the certificate

Android

  1. Download the certificate; it lands in “Downloads”.
  2. Settings → Security → Encryption & credentials → Install a certificate → CA certificate.
  3. Pick the downloaded voice-button-ca.crt and confirm.
  4. Return here: the warning is gone, and Chrome offers “Install app”.

iPhone

  1. Tap “Download the certificate” and allow the profile.
  2. Settings → Profile Downloaded → Install.
  3. Settings → General → About → Certificate Trust Settings → enable full trust for “Voice Button”.
  4. Open the page in Safari → Share → “Add to Home Screen”.

If the download does not start: on the certificate warning tap Advanced → Proceed, come back to this page and press the button again. Brave blocks such downloads entirely — open this page in Chrome.

The certificate was issued by this computer and signs only the site's address. Keep its key to yourself.

把 Voice Button 当成应用

在手机上安装一次证书：警告消失，浏览器就能把这个页面装成带图标的应用。

下载证书

Android

  1. 下载证书，文件会存到“下载”。
  2. 设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书。
  3. 选择 voice-button-ca.crt 并确认。
  4. 返回这里：警告消失，Chrome 会提供“安装应用”。

iPhone

  1. 点“下载证书”并允许安装描述文件。
  2. 设置 → 已下载描述文件 → 安装。
  3. 设置 → 通用 → 关于本机 → 证书信任设置 → 为 Voice Button 打开完全信任。
  4. 在 Safari 中打开页面 → 分享 → “添加到主屏幕”。

如果下载没有开始：在证书警告上点 “高级” → “继续前往”，回到本页再按一次按钮。Brave 会完全阻止此类下载 — 请用 Chrome 打开。

证书由这台电脑签发，仅用于该站点的地址。请保管好它的密钥。
