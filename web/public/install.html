Voice Button as an app

Install the certificate on the phone once — the warning stops and the browser lets the page install as an app with its own icon.

Download the certificate

Android

  1. Download the certificate; it lands in “Downloads”.
  2. Settings → Security → Encryption & credentials → Install a certificate → CA certificate.
  3. Pick the downloaded voice-button-ca.crt and confirm.
  4. Return here: the warning is gone, and Chrome offers “Install app”.

iPhone

  1. Tap “Download the certificate” and allow the profile.
  2. Settings → Profile Downloaded → Install.
  3. Settings → General → About → Certificate Trust Settings → enable full trust for “Voice Button”.
  4. Open the page in Safari → Share → “Add to Home Screen”.

Brave blocks certificate downloads entirely — open this page in Chrome.
